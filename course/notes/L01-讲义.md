# L01 · 引导扇区与 BIOS 输出 —— 讲义

**课程定位**：一切的地基。BIOS POST 后把磁盘第一扇区(512B)搬到 0x7C00 并跳转——你的代码从这里接管机器。

**原理（对照真实实现）**：
- 实模式：16 位、段:偏移寻址、一切靠 BIOS 中断（int 10h 显 / int 13h 盘）。
- 引导签名：扇区最后两字节必须是 0xAA55，否则 BIOS 不认。
- 0x7C00 是 IBM PC 的历史约定，全部 BIOS 启动设备都遵守。

**动手内容（对应任务书）**：
- 栈（mov ss/sp，避免刚开栈就中断的窗口）、lodsb 打印循环、串口直写（L02 重写前先借用 BIOS）。
- msg 内容与扇区签名——验收就盯串口里那句 S0: power-on OK。

**验收**：make test：QEMU 软盘引导，串口出现 S0: power-on OK。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 栈指针必须先初始化，且 SS:SP 一起赋值——中间来一次中断就会用错栈。
- 512 字节硬限：多一个字节都会挤掉 0xAA55。
