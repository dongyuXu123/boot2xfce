# L08 · 双路 console —— 讲义

**课程定位**：内核的标准输出：串口 + VGA 文本双路，print/print_hex/print_dec 三件套此后全程使用。

**原理（对照真实实现）**：
- VGA 文本模式：0xB8000 起，每字符 2 字节（ASCII+属性），80×25。
- 光标位置 = 行×80+列，写 CRTC 寄存器(0x3D4/0x3D5)高/低字节。
- 打印三件套自此成为内核唯一调试手段。

**动手内容（对应任务书）**：
- vga_putc（含换行、滚动）、print/print_hex/print_dec。

**验收**：make test：串口与 VGA 双路内容一致。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 第 0 行留给 GRUB 回显，从第 1 行开始打印。
- 滚动 = 整体内存上移一行，不是换页。
- S4 进阶：console 照 Linux vt.c 重写（struct vc 状态机/ESC 序列/CRTC 光标），课程版保留简化实现。

> 配套使用：任务书(course/L08-*/README.md)说写什么；本讲义说为什么、哪里有坑、后续演化。
