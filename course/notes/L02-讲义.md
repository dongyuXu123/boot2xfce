# L02 · COM1 串口驱动 —— 讲义

**课程定位**：串口是之后所有课的验收通道——内核测试断言全靠它输出。

**原理（对照真实实现）**：
- UART 16550：波特率除数（DLL/DLH，先置 DLAB 位）、8N1 格式、FIFO。
- 轮询发送：等 Line Status Register bit5（THR 空）再写一个字节。
- QEMU 的 -serial 把 COM1 接到宿主文件/终端，这就是测试断言的物理层。

**动手内容（对应任务书）**：
- UART 初始化四步 + 按位轮询发送函数 putc/puts。

**验收**：make test：串口日志与 L01 内容一致。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 初始化顺序错一步串口就哑——对照 osdev 的 16550 表逐位核对。
- QEMU 对非法寄存器访问宽容，真机不会——别养坏习惯。
