# S0 讲义 · 加电与实模式（L01-L03）

> 配套代码：`course/L01-boot-bios/`、`L02-serial/`、`L03-hexout/`（均已实测通过）

## L01 —— 这 512 字节为什么能统治机器

加电瞬间 CPU 从固件顶部起跑，BIOS 做完自检后只干一件与我们有关的事：按启动
顺序读每个盘的**第一个扇区**，检查最后两字节是否 `0x55 0xAA`，是则搬到
`0x7C00` 跳过去。从这条 jmp 开始，BIOS 退场，你的代码就是"操作系统"。

四个必须刻进脑子的点：

1. **`[ORG 0x7C00]`**：nasm 需要知道代码的装载地址才能算对 `msg` 这类标号。
   删掉它，`mov si, msg` 会拿到"从文件头数的偏移"，取字符串取到天边。
2. **段：地址 = 段寄存器×16 + 偏移**。把 `ds` 清零后偏移即物理地址，最简单。
   `sp=0x7C00`：栈向下长，长进代码下方的空地，永不撞代码。
3. **`int 0x10`（AH=0x0E）**：BIOS 的"电传打印"。它是软中断——不是被谁打断，
   而是主动调 BIOS 提供的函数，AH 放功能号。**这跟你以后写内核时的
   `int 0x80` 是同一个机制，只是函数从 BIOS 的换成了你的**（L16 亲手做）。
4. **`0xAA55` 签名**：`times 510-($-$$) db 0` 凑满 510 字节，`dw 0xAA55` 收尾。
   删掉它 BIOS 直接不认——建议动手试一次，看 BIOS 沉默的样子。

打印循环三件套：`lodsb`（取字符+si++ 二合一）、`or al,al`（不改值只立零
标志的判零惯用法）、`jz`（0 结尾）。`msg` 尾部 `\r\n`：屏幕要 `\n` 就够，
串口终端必须"回车"才回行首，两个都给。

## L02 —— 不求 BIOS，直接对芯片说话

16550 UART 是一段 IO 端口（COM1 从 `0x3F8` 起）。初始化就是按 datasheet
顺序 `out` 六个寄存器：IER 关中断 → LCR|0x80 开 DLAB → 除数 1（1.8432MHz
÷16÷1=115200）→ LCR=0x03（8N1）→ FIFO → MCR。发送前轮询 LSR 的 bit5
（发送保持寄存器空）再写数据口。

两个工程礼仪（以后写内核天天用）：
- **轮询硬件**：没有中断、没有回调时，`in`+`test`+`jz` 原地等是最朴素
  可靠的同步方式。
- **保护现场**：`serial_putc` 动了 AL，必须 `push ax`/`pop ax` 还回去——
  寄存器是全员共享的，"用谁之前保护谁"是汇编第一礼仪。

## L03 —— 十六进制：以后所有调试的 currency

`rol ax,4` 循环左移把最高 4 位转到最低 → `and al,0x0F` 取出 → 0-9 加 '0'、
10-15 加 `'A'-10` 再统一加 `'0'`（先把字母档抬到和数字同一坐标系）。
以后内核里打印地址、页表项、寄存器现场，全靠这 4 行循环的 32 位版。
