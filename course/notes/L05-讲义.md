# L05 · grub.cfg 与 ISO 制作 —— 讲义

**课程定位**：把裸内核做成可分发的可引导光盘镜像（grub-mkrescue），不再依赖软盘。

**原理（对照真实实现）**：
- GRUB2 靠 grub.cfg 的 menuentry 找内核：multiboot /boot/kernel.elf 一行即可。
- ISO 9660 结构由 grub-mkrescue 生成，你只提供 cfg + 内核文件的目录树。

**动手内容（对应任务书）**：
- grub.cfg（timeout=0 + menuentry）+ Makefile 的 grub-mkrescue 规则 + 目录布局 iso/boot/grub/。

**验收**：make test：光盘引导成功（与 L04 同断言）。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- grub.cfg 路径必须与 ISO 内文件布局一致（/boot/kernel.elf）。
- multiboot2 模块别顺手用——头格式完全不同，本项目用 multiboot(1)。
