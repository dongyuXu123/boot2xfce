# L04 · Multiboot 头与 1MiB 布局 —— 讲义

**课程定位**：从自己站在 0x7C00 升级为按 Multiboot 协议被 GRUB 加载到 1MiB——获得 ELF 加载与符号表能力。

**原理（对照真实实现）**：
- Multiboot 头三件套：magic=0x1BADB002、flags、checksum=-(magic+flags)，必须在前 8K 且 4K 对齐。
- flags=0x3：按页(4K)对齐加载 + 附加内存信息。链接脚本由此定内核布局。
- GRUB 跳入时 EAX=0x2BADB002（魔数校验凭证）、EBX=信息结构地址。

**动手内容（对应任务书）**：
- boot.asm 头三件套 + kernel.ld 链接脚本（.text/.data/.bss 布局与内核起止符号）。
- entry 汇编：保存 EBX、建栈、call kmain。

**验收**：make test：GRUB 引导，串口出现内核入口打印。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- flags 只能是 0x3！实测 GRUB2 对 bit6 都会 unsupported flag: 0x43 拒载——本项目踩过的第一个协议坑。
- checksum 忘取负数，GRUB 报 invalid magic——三件套相互校验。
- 信息结构指针 EBX 必须在压栈前保存，C 代码进来就没了。
