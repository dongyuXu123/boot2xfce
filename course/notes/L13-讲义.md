# L13 · 内核堆 kmalloc —— 讲义

**课程定位**：页内小块分配：首次适应 + 分裂 + 合并，内核的 malloc。

**原理（对照真实实现）**：
- 块头 12 字节（size+used+next），空闲块按地址串链；分配=首次适应，分裂出余量；释放=清 used + 向后合并。
- 堆区在链接脚本里定界（HEAP_START/END），位图预留。

**动手内容（对应任务书）**：
- kmalloc/kfree/free_split/heap_merge 四件套 + 复用实测断言。

**验收**：make test：分配→释放→再分配同地址断言绿（复用实测）。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 释放必须向后合并：不合并的话反复分配/释放会把堆打成筛子，第三次分配起就失败（课程断言连环揪出）。
- 块头必须 12B 对齐，用户数据指针返回块头+12，写穿块头就是堆腐蚀。
- 注意 kernel_end 会随内核增大而推进——它同时是 L12 低区池的下界（S4 教训）。
