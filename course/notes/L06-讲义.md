# L06 · 内存大小解析 —— 讲义

**课程定位**：内核第一次知道自己有多少内存——为内存管理画边界。

**原理（对照真实实现）**：
- Multiboot 信息结构：flags 位0=mem_lower/upper 有效；mem_lower 是低段 KB 数（≤640K），mem_upper 是 1MiB 以上 KB 数。
- 总内存 = 1MiB + mem_upper×1024。

**动手内容（对应任务书）**：
- 解析 info 结构，打印 mem_lower/mem_upper/总内存。

**验收**：make test：串口出现内存数值（QEMU -m 256 下约 256M 量级）。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 信息结构是变长的——只读 flags 声明存在的字段，别按固定偏移硬取。
- mem_upper 不含低段 640KB 实模式区。
