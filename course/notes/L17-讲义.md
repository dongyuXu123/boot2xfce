# L17 · ring3 用户程序 —— 讲义

**课程定位**：代码第一次跑在特权级 3——内核从此有用户与隔离边界。

**原理（对照真实实现）**：
- iretd 一发降级：弹 eip/cs/eflags/esp/ss，cs RPL=3 即落 ring3；后续系统调用经 int 0x80 回内核（TSS esp0 提供内核栈）。
- 用户程序平铺二进制（objcopy -O binary）嵌入内核，加载到 USER_BASE 直接执行。
- GDT 的用户码/数据段（RPL=3）此时才真正被用到。

**动手内容（对应任务书）**：
- user.c 的 sys()（int $0x80 + memory clobber）+ user_start.asm + 嵌入与加载。

**验收**：make test：ring3 用户程序经系统调用打印，内核态实测。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- sys() 内联汇编必须带 memory clobber：没有它 GCC 会把栈上缓冲的存储重排到 int 0x80 之后，用户打印空串（课程实测）。
- 平铺二进制必须 -m32 -no-pie：Ubuntu gcc 默认 PIE 生成位置无关代码，平铺后乱址（课程实测）。
- 预制 iret 帧的 eflags 必须置 IF=1（0x202）：漏了则用户代码中断全瞎（S4 if_on 课题的前身）。
- S3 进阶：fork+COW 后 iret 帧改为每任务预制（不再全局 utask_eip），trampoline_forked 恢复段+通用寄存器影像。
