# L12 · 物理页位图 PMM —— 讲义

**课程定位**：E820 普查结果变成可分配的 4KiB 物理页帧——内存管理地基，之后一切内核分配以页为单位。

**原理（对照真实实现）**：
- 位图：每物理页 1 bit，0=空闲/1=占用；分配=扫描+置位，释放=清位。
- E820 type==1 且 ≥1MiB 段才入池；基址 4K 取整、限长截断。
- 固定保留：低 1MiB（BIOS/实模式/VRAM）。

**动手内容（对应任务书）**：
- pmm_init（E820 遍历+保留区）、pmm_alloc_frame/pmm_free_frame（含 alloc/free 实测断言）。

**验收**：make test：alloc/free 往返断言绿。

**坑与历史错误**（全部来自本项目实战，非虚构）：
- 低 1MiB 必须保留（本 bug 由本课的 alloc/free 断言当场揪出）：不保留的话 alloc 从帧 0 扫起，把 BIOS 实模式区（IVT/BIOS 数据区）当可分配页发出去，机器随机崩。
- E820 段间可能有空洞（ACPI NVS、APIC），不能假设第一个可用段之后全部连续可用。
- S4 分区契约：低区 [kernel_end, 2MiB) 专供页表/PD/用户页（PDE0 可见），画布等大块走 ≥4MiB 高区——L17 分页课正式引入。
