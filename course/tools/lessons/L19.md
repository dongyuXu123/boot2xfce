# L19 · 毕业设计：第 6 个系统调用

**目标**：没有桩、没有断言——从需求到 ABI 到实现到测试，全是你。
这一课的目录是**全通状态**（前 18 课的成果合体），它只是起点和样例。

**任务**：给内核加一个新系统调用，要求：
1. 设计：调用号 6，名字和语义自己定（建议任选：
   `sys_writefile(name,buf,len)` 把用户缓冲写进 ramfs /
   `sys_reboot` 模拟重置 ticks / `sys_tasklist` 打印任务表……）。
2. 实现：`syscall.c` 加 case；需要改用户程序就同步 `user.c`。
3. 测试：在 Makefile 的 test 目标**自己加一条串口断言**，
   `make test` 绿才算数。
4. 记录：在本 README 末尾追加你的设计说明（ABI/坑/想改的地方）。

**毕业标准**：`make test` 全绿（含你自己加的断言）+ 能对别人讲清楚
"从 int $0x80 到 iretd 回到 ring3" 中间发生的每一件事。

完成后：恭喜，S2 毕业 🎉。S3 从 `cp -r 本目录 ../s3-lab` 开始——
第一课是分页。到时候见。
