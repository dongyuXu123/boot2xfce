# L03 · 十六进制打印（寄存器与循环练习）

**目标**：以后调试内核全靠打十六进制，现在就把它焊进肌肉记忆。
**你亲手写**：`print_ax_hex`——把 AX 按四位**大写**十六进制打出，
每位经 `putc2`（BIOS+串口双路，已给定）输出。程序末尾会以 AX=0x1234
调用它，串口须出现 `AX=1234`。

**提示**：
- 循环 4 次：`rol ax,4` 把最高 4 位转到最低 → `and al,0x0F` 取出 →
  ≤9 加 `'0'`，10-15 加 `'A'-10` 再统一加 `'0'`（想想为什么能统一）。
- `putc2` 会改哪些寄存器？该 `push` 保护的先保护。
- 别忘了 `cx` 计数器是谁的、`loop` 用的就是它。

**验收**：`make test` 断言 `S0: power-on OK` 和 `AX=1234` 同时出现。
